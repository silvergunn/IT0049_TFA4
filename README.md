# SimplePOS TFA4

SimplePOS is a CodeIgniter 4 point-of-sale workspace that manages customer and staff records. TFA4 adds session-based authentication, hashed passwords, protected routes, and logout functionality.

## Features

- Customer account management
- User account management
- User profile picture upload
- Secure staff login
- Password hashing with `password_hash()`
- Password verification with `password_verify()`
- Session-based authentication
- CodeIgniter authentication filter
- Protected Customers and Users routes
- Secure POST logout with CSRF protection
- Responsive authentication interface

## Requirements

- PHP 8.1 or newer
- MySQL or MariaDB
- Apache
- Composer
- CodeIgniter 4
- XAMPP is recommended for local setup
